# データを集計して、表とグラフにまとめる手順

1. 列を確かめる: 列の名前と型、行の数、空の値の数を、コードの実行（pandas）か `list_database_tables` で見る。依頼の言葉と列の意味がずれていたら、先に質問する。
2. 集計する: 合計・平均・件数などは、コードの実行かデータベースの集計で出す。期間や絞り込みの条件を書き留める。
3. 表とグラフを作る: 表は CSV か Excel、グラフは PNG で、作業フォルダに保存する。グラフには題と、軸の名前と単位を付ける。
4. 確かめる: 集計した合計が、もとのデータの合計と合うかを、もう一度コードで確かめる。
5. 報告する: 結論から書き、使ったファイルや表、集計の条件、作ったファイルの場所を添える。
