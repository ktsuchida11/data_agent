# pytest でテストを書く手順

1. テスト対象の関数の入出力と、境界値（空・0・最大・不正な型）を洗い出す。
2. `tests/test_<モジュール名>.py` に書く。1テスト1観点、名前は `test_<対象>_<条件>_<期待>`。
3. 外部（ネットワーク・時刻・乱数）に依存する部分は引数で差し替えられるようにするか、`monkeypatch` で固定する。
4. 失敗したら、まずエラーメッセージと該当行を読む。テストを通すために期待値を変えるのは、仕様が間違っていたと確認できたときだけ。
