# 1. 動かしてみる

data_agent を起動して、画面で話してみます。すでに毎日使っているなら、最後の「いまのパックを確かめる」だけ読めば十分です。

## 用意するもの

- Docker Desktop（起動しておく）
- uv（Python の道具。`uv --version` で確かめる）
- Anthropic の API キー
- 手元の Langfuse（会話の保存先の PostgreSQL として使う。起動しておく）

## 手順

1. 設定のファイルを作ります。初めてのときだけです。
   ```bash
   cd ~/pg_work_space/t_claw/LangChain/data_agent
   cp example.env .env
   ```
   `.env` をエディタで開き、`ANTHROPIC_API_KEY` と、ログインの 3 項目（`CHAINLIT_AUTH_SECRET`・`APP_USERNAME`・`APP_PASSWORD_SHA256`）を書きます。値の作り方は、`.env` の中の説明にあります。
2. 会話の保存先を作ります。初めてのときだけです。
   ```bash
   bash scripts/setup_local_db.sh
   ```
3. 起動します。`-d` を付けると、起動したあとにターミナルが戻ってきます。
   ```bash
   docker compose up --build -d
   ```
4. ブラウザで http://127.0.0.1:8000 を開き、`.env` に書いた名前とパスワードでログインします。
5. 話しかけてみます。たとえば「作業フォルダに何がある？」。

## 止める・ログを見る

```bash
docker compose logs -f data-agent
docker compose down
```

1 行目はアプリのログを見るコマンドです（Ctrl+C で抜けても、アプリは止まりません）。2 行目で止めます。

## いまのパックを確かめる

どの用途パックで動いているか、どのツールをどう扱うかは、次のコマンドで分かります。サーバーにはつながず、何も実行しません。

```bash
uv run python -m data_agent.tools.registry
```

出る内容の例（データ分析のパック）:

```
用途パック: data（データ分析エージェント）
役割の文: packs/data/SYSTEM.md（1,301 文字）
あいさつ: データ分析エージェントです。作業フォルダ `workspace/` の中で作業します。
ツール（名前 / 画面の名前 / 確認 / 毎回確認のチャット / 送る前の確かめ / 回数の上限 / 照合）:
  run_python / コードの実行 / 確認: しない / 確かめる / しない / - / 根拠にする
  list_database_tables / データベースの表の一覧 / 確認: しない / 確かめない / しない / - / -
  query_database / データベースの問い合わせ / 確認: しない / 確かめる / しない / - / 根拠にする
  web_search / Web 検索 / 確認: 怪しいとき / 確かめる / しない / 5 / 根拠にする
（ほかに、ファイルの読み書きなど、Deep Agents が元から持つツールがある）
```

- **確認:** 実行の前に、画面で「実行してよいか」を聞くか。「怪しいとき」は、送る内容に、外に出したくない情報らしいもの（このチャットで読んだデータの写しや、見張る言葉）があるときだけ聞く。
- **毎回確認のチャット:** 画面の設定欄で「毎回確認」を選んだチャットで、聞くか。
- **送る前の確かめ:** 引数に鍵や個人情報があれば、送らずに止めるか。
- **照合:** 返事の数を確かめるときに、このツールの結果を根拠にするか（ADR-0026）。
