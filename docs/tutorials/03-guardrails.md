# 3. 守りの設定を変える

守りの設定は `config/security.yaml` にあり、どの用途パックにも共通です。変えたら、作り直します（`docker compose up --build -d`）。

## よく変える項目

| 項目 | 意味 | 既定 |
|---|---|---|
| `approvals.default_mode` | 新しいチャットの確認のしかた。`standard`: 削除と、確認すると決めたツールだけ。`strict`: 書き込み・実行・検索・パックのツールも毎回 | `standard` |
| `approvals.allow_mode_change` | 利用者が、画面の設定欄で確認のしかたを切り替えられるか | `true` |
| `limits.max_model_calls_per_run` | 1 回の依頼でモデルを呼べる回数（料金の上限の目安） | 60 |
| `limits.max_tool_calls_per_run` | 1 回の依頼でツールを呼べる回数 | 120 |
| `guardrails.actions` | 見つけたものの扱い（`mask`: 伏せる、`log`: 記録だけ、`off`: 何もしない） | どれも `mask` |
| `guardrails.custom_rules` | 用途ごとの番号を見つけるルール（下で説明） | なし |
| `tracing.retention_days` | Langfuse に送った記録を残す日数（ADR-0031） | 90 |

ツールごとの確認と回数の上限は、ツールを書いた場所で決めます。

- **MCP のツール:** パックの `pack.yaml`（[4](04-mcp.md)）に書きます。
- **Python のツール:** `@agent_tool` に書きます（[5](05-python-tool.md)）。
- **組み込みのツール:** `security.yaml` の `code_execution`・`database`・`web_search` に書きます。

## 用途ごとの番号を、ガードレールで伏せる

ガードレールが元から見つけるのは、鍵、カード番号、マイナンバー、メールアドレス、電話番号、口座番号です。社員番号や案件のコードのように、用途ごとに形が決まっている番号は、`custom_rules` に正規表現で書き足せます。

1. `config/security.yaml` の `guardrails:` の中に、次のように足します（`actions:` と同じ深さ）。
   ```yaml
     custom_rules:
       - kind: employee_id          # 監査ログで使う名前（英小文字・数字・_）
         label: 社員番号            # 伏せたあとに「[マスク済み:社員番号]」と出る
         pattern: 'EMP-\d{6}'       # 正規表現。'…' で囲む
         action: mask               # mask・log・off（省略すると mask）
   ```
2. 試します。いまの設定のガードレールに文章を通して、どう伏せられるかを見ます。
   ```bash
   uv run python -m data_agent.safety.guardrails "担当は EMP-123456 です"
   ```
   `結果: 担当は [マスク済み:社員番号] です` と出れば、効いています。
3. 作り直します。
   ```bash
   docker compose up --build -d
   ```

**受け付けない書き方（起動の前に止まります）:**

- 読めない正規表現
- 何にでも一致するもの（`.*` など）
- 元からある種類と同じ名前（`email` など）

**伏せたものの扱い:**

- 利用者の入力、ツールの結果、モデルの返事、どれにも効きます。
- 伏せる前の値は、モデルにも、画面の履歴にも、監査ログにも残りません。
- 外に送るツール（MCP のツールなど）の引数に含まれていれば、送らずに止めます。

## 気をつけること

- **伏せすぎると、仕事ができなくなります。** たとえばメールアドレスを伏せると、メールアドレスで顧客を探す作業はできません。必要なら、その種類だけ `log` にします。どの種類を伏せるかは、用途ごとに決めて、ADR に残します。
- **形が決まっていないもの（氏名、住所など）は、ガードレールでは見つけられません。** データベースの列を読めなくする（ADR-0019）、見張る言葉（ADR-0022）、確認（ADR-0021）で守ります。
