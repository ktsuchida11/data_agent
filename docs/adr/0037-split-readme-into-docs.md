# ADR-0037: README を短くし、使い方などの説明を docs/ の 6 つの資料に分ける

- **状態:** 採用（実装済み）。オーナーが決めた（2026-11-18。「READMEの内容が長すぎるので、分割してdocsに保存するようにして欲しいです」）。フォルダの表は、2026-11-19 に README の「フォルダの地図」に一本化した（→ ADR-0039）
- **日付:** 2026-11-18
- **決定者:** プロジェクトオーナー
- **対象:** data_agent

## 状況

- README は 396 行あった。動かし方、機能と守りの説明（20 を超える節）、開発の確かめ方、フォルダの表、進捗が 1 つのファイルに並び、知りたいことを探しにくかった。
- フォルダの表は、`docs/architecture.md` の「6. ファイルの地図」と中身が重なっていた（ADR-0028 で、細かい地図は説明書に一本化すると決めていた）。

## 決定

1. **README は、何をするアプリか、最短の動かし方、できることの要約、資料の案内、コードを変えたときの 3 つのコマンドだけにする**（49 行）。
2. **説明は、読む人のしたいことごとに、`docs/` の 6 つの資料に分ける。**

   | 資料 | 中身（もとの README の節） |
   |---|---|
   | `docs/setup.md` | 手元で動かす、コンテナで動かす、会話を PostgreSQL に保存する、Langfuse へのトレースの送信 |
   | `docs/usage.md` | 過去のチャット（一覧・アーカイブ・グループ）、定時実行、スキルの提案と登録、コードの実行、データベースからデータを取る、Web 検索、モデルの切り替え |
   | `docs/safety.md` | 操作の前の確認、回数の上限、Web 検索の前の確認、ガードレールと監査ログ、返事の数の照合、接続元の検査、エージェントから見えるもの |
   | `docs/development.md` | コードを変えたときの確認、画面の回帰確認、安全性の点検（依存の脆弱性、指示の乗っ取り、誤情報） |
   | `docs/packs.md` | 別の用途に使う（用途パック）、社内 API をつなぐ（MCP） |
   | `docs/progress.md` | 進捗（フェーズ） |

3. **文は書き換えずに移す。** 変えたのは、見出しの深さと、ほかの節を指す言葉（「下の『操作の前の確認』」→「守りの仕組みの『操作の前の確認』」）とリンクの行き先だけ。
4. **README のフォルダの表はなくし、`docs/architecture.md` の「6. ファイルの地図」に一本化する。** 地図になかった `chainlit.md`、`AGENTS.md`・`CLAUDE.md`、`.github/workflows/ci.yml`、`docs/*.md` は、地図に足した。（→ 2026-11-19 に、フォルダの表は README に一本化し、説明書の地図は `src/` の中と、資料・ファイルの表だけにした。ADR-0039）

## 検討した案

| 案 | 内容 | 判断 |
|---|---|---|
| **A. したいことごとに 6 つに分ける** | 動かす・使う・守り・開発・別の用途・進捗 | **採用**。1 つの資料が 13〜129 行に収まり、README の案内の表から選べる |
| B. 機能ごとに 1 つずつ分ける | 定時実行、スキル、Web 検索…を別の資料にする | 不採用。資料が 20 ほどになり、どれを開けばよいかが分かりにくい |
| C. 2 つに分ける | 使う人向けと、開発する人向け | 不採用。使う人向けが 300 行近く残り、長いままになる |

## 確かめたこと（2026-11-18）

- **移し漏れ:** もとの README の、空でない行のすべて（フォルダの表と、最初の紹介文を除く）が、6 つの資料のどれかにあることを、スクリプトで確かめた。
- **リンク:** git で管理しているすべての Markdown の、ほかの資料へのリンクの行き先があることを確かめた（切れたリンク 0 本）。
- **単体テスト・点検:** `uv run --offline pytest -q`、`ruff format --check`、`ruff check` が通った。

## 分かっている制約

- ADR の中の「README の『…』」という書き方は、当時の記録なので直していない。いまの場所は、ADR-0002・0028・0034 に「→」で書き足した。
