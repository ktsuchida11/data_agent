# ADR-0013: 画面は Chainlit の標準機能と、コマンド・ボタン・設定欄で作る

- **状態:** 提案中。オーナーの確認はまだ取れていない
- **日付:** 2026-11-13
- **決定者:** プロジェクトオーナー
- **対象:** data_agent

## 状況

- 画面には Chainlit を使っていますが、「どこまで Chainlit の標準に任せ、どこから独自に作るか」を決めていませんでした。
- アーカイブとグループ分けでは、画面を作り替えずに、チャットの中のコマンドで補う方式を選びました（ADR-0011）。
- これから画面に足したい機能が、ほかの ADR にいくつか残っています。作るたびに方式を迷わないよう、方針をまとめます。

## 決定（提案）

- **Chainlit の標準の画面を使い続けます。**
- **足りない操作は、Chainlit が用意している4つの仕組みで補います。** 画面そのものの作り替え（独自の JavaScript の追加や、画面の独自ビルド）はしません。

| 仕組み | 向いている操作 | 例 |
|---|---|---|
| **コマンド**（入力欄で `/`） | いま開いているチャットに対する操作 | アーカイブ、グループ分け |
| **メッセージのボタン** | その場で選んで答える操作 | 削除の承認、アーカイブから戻す |
| **設定欄**（入力欄の設定ボタン） | チャットの間ずっと効く設定 | モデルの切り替え |
| **チャットを始めるときの選択**（チャットプロファイル） | 用途ごとの使い分け | コーディング用と調査用の切り替え |

エージェントが作った画像やファイルは、メッセージの添付として出します（Chainlit の標準の機能。ADR-0016）。

- **表示は日本語にします。** Chainlit の日本語の翻訳ファイルは、すでに入っています。

## これから足す機能と、置き場所の案

| 機能 | 置き場所 | 関連 |
|---|---|---|
| モデルの切り替え（2026-11-13 に実装済み） | 設定欄 | ADR-0014 |
| 手動でのコンテキストの圧縮 | コマンド | ADR-0004 |
| 定時実行の登録・一覧・停止・削除（2026-11-13 に実装済み） | コマンドとボタン | ADR-0006 |
| スキルの提案の承認（2026-11-14 に実装済み） | コマンドとメッセージのボタン | ADR-0007 |
| ガードレールが働いたことの通知 | メッセージ | ADR-0012 |
| コードが作った画像・ファイルの表示（2026-11-14 に実装済み） | メッセージの添付 | ADR-0016 |

モデルの切り替え、定時実行、スキルの提案の承認、ガードレールが働いたことの通知は実装済みです。残りは、手動でのコンテキストの圧縮です。

## 検討した選択肢

| | A. 標準の画面＋4つの仕組み（提案） | B. Chainlit の画面を改造する | C. 画面を Chainlit 以外で作り直す |
|---|---|---|---|
| **作る量** | 小 | 大 | 最大 |
| **できること** | Chainlit が用意している範囲 | 一覧の見出しやドラッグなども作れる | 自由 |
| **Chainlit を上げたときの影響** | 小 | 大 | なし |

## この方式の限界

- **左側の一覧は変えられません。** グループごとの見出しや、一覧の上でのアーカイブの操作は作れません（ADR-0011）。
- **コマンドは、知っている人しか使えません。** 最初の挨拶で `/` を案内していますが、ボタンに比べると気づきにくいです。

## 見直す条件

- 左側の一覧そのものを作り替えたくなったとき（ADR-0011 の選択肢 B）。
- Chainlit の4つの仕組みでは置き場所がない機能が出てきたとき。
