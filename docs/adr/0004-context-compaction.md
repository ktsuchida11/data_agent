# ADR-0004: コンテキストの圧縮は Deep Agents 標準の自動要約に任せる

- **状態:** 記録（既存の設計）
- **日付:** 2026-11-13（設計はフェーズ1の時点のもの）
- **決定者:** プロジェクトオーナー

## 状況

「コンテキストを圧縮する機能はあるのか」という質問が出たので、現行の動作を記録します。
会話が長くなるとモデルに渡せる量（コンテキスト）の上限に近づくので、古い部分を要約して減らす仕組みが必要です。

## 決定（現行の設計）

- **圧縮は `create_deep_agent` が標準で組み込む自動要約に任せます。** 追加の設定はしていません。
- deepagents 0.7.32 のコードによると、動作は次のとおりです。
  - コンテキスト上限の約85%に達すると発動します。モデルの上限が分からない場合は 170,000 トークンで発動します。
  - 直近の約10%を残し、それより古い会話を要約に置き換えます。
  - 元の会話は `/conversation_history/<セッションID>.md` に退避します。この構成では `workspace/conversation_history/` に当たります。

実際に発動させての確認はしていません。上の内容はコードを読んだ結果です。

## 影響

- 長い作業でも、上限に達して止まることを避けられます。
- 退避したファイルは `workspace/` の中にできるので、エージェントからも見えます。
- 好きなタイミングで手動で圧縮する手段はありません。

## 追記（2026-11-13）: 本物のモデルで確かめる必要がある点

Claude API の資料によると、新しい世代のモデルでは、モデルの思考の記録が「その時点までの会話」に結び付けられています。
古い会話を要約に置き換え、直近の会話をそのまま残す形の圧縮では、残した部分の思考の記録が無効と判定され、API がエラーを返すことがあります。
この確認は、2026年8月31日以降に作られたアカウントでは既定で有効で、Fable 5.2 ではすべてのアカウントで有効です。

Deep Agents 標準の自動要約は、この形の圧縮です。LangChain の側で対処されているかは確認していません。
長い会話で要約が発動したときにエラーにならないかを、本物のモデルで確かめる必要があります。

## 未決事項

- 手動の圧縮（Claude Code の `/compact` に当たる機能）を足すか。`create_summarization_tool_middleware` を追加すると、エージェントが `compact_conversation` ツールで圧縮できるようになります。
