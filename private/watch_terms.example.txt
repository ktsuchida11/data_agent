# 見張る言葉の一覧の書き方（ADR-0022）
#
# Web 検索の質問文にここの言葉が入っていたら、検索の前に、質問文を画面に出して確かめます。
# 利用者が自分で書いた場合も、確かめます。顧客や取引先の名前、外に出したくない案件の名前などを書きます。
#
# 使い方: このファイルを watch_terms.txt という名前で写して、言葉を書き換えます。
#   - 1行に1つ。# で始まる行と、空の行は読みません。
#   - 全角・半角、大文字・小文字、空白の違いは、気にしなくてかまいません（そろえて比べます）。
#   - 日本語を含む言葉は 2 文字以上、英数字だけの言葉は 3 文字以上にしてください（短いものは読みません）。
#   - 英数字だけの言葉は、語の切れ目で比べます（acme は「acme corp」に当たり、「acmesoft」には当たりません）。
#   - ファイルを書き換えると、アプリを動かしたまま、次の検索から使われます。
#
# このフォルダ（private/）は、コンテナのイメージに入りません（.dockerignore）。
# compose.yaml で、読み取り専用で /app/private に渡します。エージェントからは読めません。
#
# 下は例です（架空の名前）。
みどり商会
あおぞら工業
Hikari Bussan
